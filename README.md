📦 Gerenciador Inteligente de Estoque
Sistema de gestão de estoque inteligente com automação de reposição e previsão de demanda via Machine Learning.

🚀 Tecnologias Utilizadas
Streamlit: Interface web responsiva e interativa.

Scikit-Learn: Modelo de Regressão Linear para previsão de demanda.

Pandas: Processamento de dados e manipulação de inventário.

SMTP (Gmail API): Automação de alertas de ruptura de estoque.

💡 Funcionalidades Principais
Gestão CRUD: Adição, edição e controle de inventário em tempo real.

IA Preditiva: Estimativa de saída de produtos para os próximos 7 dias.

Monitoramento Reativo: Sistema automático que detecta estoque crítico e envia relatório via e-mail.

Segurança: Sistema de autenticação administrativa persistente.

🛠️ Como rodar o projeto

Clone este repositório.

Instale as dependências: pip install -r requirements.txt

Configure suas credenciais de e-mail no app.py.

Execute: streamlit run app.py
